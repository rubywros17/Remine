# Remine 디자인 기준 (3안)

앱 구현의 **유일한 디자인 기준**이다. 시안 이미지(`docs/design/v3/01~05.png`)는 이 문서를 만들 때 한 번 참고했고, 시안과 이 문서가 다르면 **이 문서를 따른다**(차이는 [시안과 다른 점](#시안과-다른-점) 참고). 코드의 토큰은 `app/lib/core/tokens.dart` 한 파일이 이 문서의 값을 그대로 옮긴 것이다.

---

## 1. 색

| 토큰 | HEX | 쓰는 곳 |
|---|---|---|
| `background` 바탕 | `#FBFBF8` | 앱 전체 배경 |
| `ink` 글자 | `#111111` | 본문·제목, 셀라돈·레몬·연셀라돈·칩 위 글자 |
| `inkSub` 보조 글자 | `#6F6F71` | 날짜·출처·부가 설명 (**칩·셀라돈 위에는 쓰지 않는다**) |
| `darkGray` 다크그레이 | `#4A4B4E` | 관심사 카드, 주요 버튼, 첫 분석 배경. 위 글자는 흰색 |
| `celadon` 셀라돈 | `#7DC4CE` | 브랜드 **면·버튼**: 가장 많은 카테고리 알약, 상세 화면 배경, 분석 화면의 큰 진행 숫자(다크 위) |
| `celadonDeep` 딥 셀라돈 | `#3E8D98` | **바탕 위 큰 숫자 전용**(카테고리 화면의 개수). 작은 글자에는 쓰지 않는다 |
| `celadonSoft` 연셀라돈 | `#DDEFF2` | 해시태그 칩, 탭 선택 표시 |
| `lemon` 레몬 | `#EDE7B3` | 관심사 라벨·형광펜·선택 항목(선택된 태그 칩·카테고리 타일)·"더 보기" 버튼 |
| `chip` 칩 배경 | `#EEF0F0` | 개수 배지, 아이콘 배경, 중립 칩 |
| `border` 테두리 | `#E1E3E3` | 카드·타일의 얇은 테두리(장식) |
| `white` | `#FFFFFF` | 시트 타일, 날짜 배지, 분석 화면 칩 |

- 셀라돈·레몬 위 글자는 항상 `#111111`.
- 썸네일 플레이스홀더(가짜 데이터)는 셀라돈 계열 + 회색 계열 색 블록을 돌려 쓴다.
- 다크 모드는 이번 범위에 없다(라이트 고정).

## 2. 폰트

| 용도 | 폰트 | 라이선스 |
|---|---|---|
| 한글 | Pretendard (400 / 600 / 700) | SIL OFL 1.1 — `app/assets/fonts/Pretendard-OFL.txt` |

숫자(개수, 날짜, ×N, 진행 숫자)와 영문 라벨(`remine.`, `MON 10.19`)은 Space Grotesk, 나머지는 Pretendard.

|---|---|
| `display` 홈 큰 제목 | Pretendard 700 / 30 / 1.25 |
| `title` 화면 제목 | Pretendard 700 / 36 / 1.1 |
| `sectionTitle` | Pretendard 700 / 18 / 1.3 |
| `cardTitle` 요약 제목 | Pretendard 700 / 20 / 1.35 |
| `body` | Pretendard 400 / 15 / 1.5 |
| `label` 칩·버튼 | Pretendard 600 / 14 / 1.2 |
| `caption` | Pretendard 400 / 12 / 1.3 |

## 4. 회전

회전은 **장식**(썸네일 콜라주·스티커·상세 이미지 카드)에만 쓴다. 누르는 요소(칩·버튼·타일·탭)는 회전 0~2°까지. 장식 회전은 접근성 트리와 무관하다.

## 5. 모션

| 토큰 | 값 |
|---|---|
| duration `fast` / `base` / `slow` | 120ms / 240ms / 420ms |
| curve `standard` | `easeOutCubic` (대부분의 진입·상태 변화) |
| curve `emphasized` | `Cubic(0.2, 0, 0, 1)` (화면 전환, Hero) |
| curve `exit` | `easeInCubic` (퇴장) |
| spring | mass 1 / stiffness 300 / damping 22 (시트·눌림 반응) |

- `MediaQuery.disableAnimationsOf(context)`가 true(시스템의 "애니메이션 줄이기")면 **모든 duration은 0**, 화면·시트·탭 전환은 즉시 바뀐다.
- 썸네일은 홈 → 카테고리 → 상세로 Hero 전환한다(태그 `screenshot-{id}`).

## 7. 말투

- UI 문구는 가벼운 **반말**: "이거 어디 서랍이야?", "응, 쇼핑 맞아", "이 서랍으로 옮기기".
- **개인정보·오류 안내는 해요체**: "은행·메신저 캡처, 민감한 정보가 보이는 캡처는 폰 밖으로 안 나가요."

## 8. 화면

공통: 바탕 `background`, 좌우 여백 22, 하단 탭바는 홈(서랍 탭)에만 고정.

### 8.1 홈 (서랍 탭)
위에서 아래로:
1. 상단 줄: 왼쪽 `remine.`(Space Grotesk 700 20), 오른쪽 날짜 알약(`MON 10.19`, 1px `ink` 테두리, `numBadge`).
2. 큰 제목 `display` "잊고 있던 거, / 다시 캐냈어요" — **"캐냈어요"에 레몬 형광펜**(글자 아래쪽 절반을 칠한 띠).
3. **관심사 카드**(`darkGray`, 반경 28, 높이 약 196): 왼쪽 위 "잊은 관심사" 레몬 스티커(알약), 큰 숫자 `×N`(`numXL`, 흰색), `#태그`(흰색 굵게), 설명 "2주 동안 N번 캡처 · N일째 잠자는 중"(흰색 70%); 오른쪽에 기울어진 썸네일 3장(장식 회전). 누르면 그 태그가 선택된 카테고리 화면으로 이동.
4. 섹션 제목 "내 캡처 서랍" + 오른쪽 총 장수(`N shots`, 보조 글자).
5. **카테고리 알약**: 아이콘 · 이름 · 개수 배지, `Wrap`으로 줄바꿈. **개수 내림차순, 기타는 항상 마지막.** 개수가 가장 많은 알약만 `celadon` 채움(개수 배지는 `ink` 채움에 흰 글자), 나머지는 `background` + 1px `ink` 테두리(개수 배지는 `chip` 채움).
6. 하단 고정 탭바 3개(서랍·관심사·검색). 선택 탭은 `celadonSoft` 알약 배경 + 굵은 라벨. 관심사·검색은 빈 화면 자리만(안내 문구 한 줄).

### 8.2 카테고리 상세
1. 뒤로 버튼(아이콘만, 터치 영역 48).
2. 큰 제목(카테고리 이름 `title`) + **오른쪽 거대한 개수(`numHero`, `celadonDeep`)**.
3. 태그 칩 줄(가로 스크롤): 중립 칩은 `background` + `ink` 테두리 알약, **선택된 칩은 `lemon` 채움**. 맨 앞 "전체" 칩. 같은 칩을 다시 누르면 해제.
4. 높이가 다른 **2열 엇갈림 그리드**: 카드 반경 28, 썸네일 색 블록, 왼쪽 아래에 날짜 배지(`MM.DD`, 흰색 알약). 칩 줄과 겹치지 않는다. 누르면 상세로 Hero 전환.

### 8.3 스크린샷 상세
1. 배경 `celadon`. 위쪽: 뒤로 버튼(흰 원).
2. 가운데: 살짝 기울어진(약 -3°~+3°) 흰 이미지 카드(플레이스홀더) + 오른쪽 위에 `#태그` 레몬 스티커.
3. 하단 카드(`background`, 위쪽 반경 28~): 첫 줄 "출처 · 10.19 14:14"(보조 글자) + 오른쪽 **카테고리 칩**(아이콘 + 이름 + 연필, 누르면 수정 시트); 요약 제목(`cardTitle`); 연셀라돈 해시태그 칩들; **레몬 버튼** "같은 관심사 캡처 N장 더 보기" + 화살표.

### 8.4 카테고리 수정 시트
- 위쪽 반경 30의 `background` 시트, 뒤는 상세 화면이 어둡지 않게 비친다. 오른쪽 위 닫기(×) 버튼(`chip` 원).
- 제목 "이거 어디 서랍이야?", 부제 "AI는 **X**라고 했어요"(`autoCategory`, X는 굵게, 보조 글자).
- **2열 타일**(흰색, 1px `border`, 반경 18): 아이콘(`chip` 원 배경)·이름. 선택(현재 값)은 **`lemon` 채움 + 2px `ink` 테두리 + 체크**. 일곱 번째(기타)는 왼쪽 열.
- 아래 `darkGray` 버튼(흰 글자): 선택값이 **현재 카테고리와 같으면 "응, X 맞아"**, **다르면 "이 서랍으로 옮기기"**. 누르면 저장(`categorySource = USER`) 후 시트가 닫히고 상세·홈 집계에 반영된다. 같은 값도 저장된다(사용자 확인).

### 8.5 첫 분석 (정적)
- 배경 `darkGray`. 상단 `remine.`(흰색) + 오른쪽 `DIGGING…` 알약(흰 테두리).
- 거대한 진행 숫자(`numHero` 128, `celadon`) + "/ N장 꺼냈어요"(흰색 굵게).
- 썸네일 콜라주(장식 회전, 셀라돈·연셀라돈·레몬·흰색 카드) + "→ 쇼핑" 레몬 스티커.
- 카테고리별 개수 칩(흰색 알약, 이름 + 개수 `chip` 배지) `Wrap`.
- 하단 개인정보 안내 카드(`background`, 자물쇠 아이콘, 해요체): "은행·메신저 캡처, 민감한 정보가 보이는 캡처는 폰 밖으로 안 나가요."
- 지금은 가짜 진행값(128 / 300)의 정적 화면이다. 시그니처 모션은 이후.

## 9. 접근성

- 터치 영역 최소 48×48. 아이콘만 있는 버튼은 `Semantics` 라벨 필수.
- 장식(썸네일 콜라주, 스티커)은 `ExcludeSemantics`. 큰 개수·진행 숫자는 읽히게 한다("쇼핑 42장").
- 선택 상태는 색에만 의존하지 않는다(체크·굵은 테두리).
- 애니메이션 줄이기를 따른다([모션](#5-모션)).

## 시안과 다른 점

| 항목 | 시안 | 이 문서 |
|---|---|---|
| 카테고리 알약 순서·색 | 순서 임의, 문화생활이 레몬 | 개수 내림차순(기타 마지막), 가장 많은 하나만 셀라돈, 레몬은 선택 항목 전용 |
| 카테고리 화면 "+5 this week" | 있음 | 없음(데이터 없음) |
| 상세 "3 / 42" 위치 표시 | 있음 | 없음 |
| 카테고리 화면 태그 칩 줄 | 첫 타일이 가림 | 겹치지 않음 |
| 카테고리 화면 큰 숫자 색 | 셀라돈 `#7DC4CE`(바탕 대비 1.90) | 딥 셀라돈 `#3E8D98`(3.70) |
| 시트 닫기(×) | 있음 | 유지 |
| 분석 화면 `DIGGING…`, "→ 쇼핑" 스티커 | 있음 | 유지(장식) |
