# Remine 디자인 기준 (3안)

앱 구현의 **유일한 디자인 기준**이다. 시안 이미지(`docs/design/v3/01~05.png`)는 이 문서를 만들 때 한 번 참고했고, 시안과 이 문서가 다르면 **이 문서를 따른다**(차이는 [시안과 다른 점](#시안과-다른-점) 참고). 코드의 토큰은 `app/lib/core/tokens.dart` 한 파일이 이 문서의 값을 그대로 옮긴 것이다.

### 카테고리 색 (`AppCategoryColors`)

홈 비율 막대의 칸과 알약 앞 점에 쓴다. 기존 토큰과 같은 값은 그 토큰을 그대로 쓴다.

| 카테고리 | HEX | 토큰 |
|---|---|---|
| 쇼핑 | `#7DC4CE` | `celadon` |
| 문화생활 | `#A8C49A` | (새 값) |
| 장소 | `#C3B8E0` | (새 값) |
| 정보 | `#EDE7B3` | `lemon` |
| 대화 | `#A9B7C6` | (새 값) |
| 일정 | `#F2B8A0` | (새 값) |
| 기타 | `#E1E3E3` | `border` |

- 7색 모두 밝아서 점에는 전부 1px `ink` 15%(`#26111111`) 테두리를 두른다. 막대 칸에는 테두리가 없다(칸 사이 간격으로 구분).
- 카테고리 알약 테두리는 `darkGray` 차콜 `#4A4B4E`(`AppCategoryColors.pillBorder`).
- 색만으로 정보를 전하지 않는다: 알약에 이름·개수가 있고 막대는 화면 읽기 라벨로 읽는다.

- 셀라돈·레몬 위 글자는 항상 `#111111`.
- 썸네일: 기기 모드에서는 asset id로 **기기 사진**을 보여 준다(기기에서 지워졌으면 "사진이 없어요" 자리 표시). 가짜 데이터 모드(크롬·테스트)에서만 셀라돈 계열 + 회색 계열 색 블록을 돌려 쓴다.
- 다크 모드는 이번 범위에 없다(라이트 고정).

## 4. 회전

회전은 **장식**(썸네일 콜라주·스티커·상세 이미지 카드)에만 쓴다. 누르는 요소(칩·버튼·타일·탭)는 회전 0~2°까지. 장식 회전은 접근성 트리와 무관하다.

## 8. 화면

공통: 바탕 `background`, 좌우 여백 22, 하단 탭바는 홈(서랍 탭)에만 고정.

### 8.1 홈 (서랍 탭)
위에서 아래로:
1. 상단 줄: 왼쪽 `re:mine`(Space Grotesk 700 20, 소문자, 콜론만 `celadonDeep` #3E8D98·나머지 글자색, 화면 읽기 "Remine", `Wordmark` 위젯), 오른쪽 날짜 알약(`MON 10.19`, 1px `ink` 테두리, `numBadge`).
2. 큰 제목 `display` "잊고 있던 거, / 다시 캐냈어요" — **"캐냈어요"에 레몬 형광펜**(글자 아래쪽 절반을 칠한 띠).
3. **관심사 카드**(`darkGray`, 반경 28, 최소 높이 168 — 360×800에서 3장): 왼쪽 위 상태 스티커(마지막 캡처 7일 미만 셀라돈 "요즘 빠진 것", 7일 이상 레몬 "잊은 관심사" + 레몬 테두리 2px), 주인공 `#태그`(`display` 30, 흰색, 최대 2줄), 그 아래 `linkedTags` 최대 3개 "#도안 · #코스터"(흰색 75%); 왼쪽 아래 점 5칸 게이지(3·6·10·15·20장 이상마다 셀라돈 1칸, 잊은 관심사는 레몬 1칸) + "오늘/어제/N일 전 마지막" 또는 "N일째 잠자는 중"; 오른쪽 기울어진 썸네일 3장 위에 10° 기울인 원형 스티커 "19 / SHOTS"(지름 58, 흰색·잊은 것은 레몬), 카드 뒤 외곽선만 있는 큰 숫자 워터마크(132, 흰색 14%, 글자 크기 설정 무시). 값은 `AppInterestCard`. 누르면 태그 모아보기.
4. 섹션 제목 "내 캡처 서랍" + 오른쪽 총 장수(`N shots`, 보조 글자).
5. **비율 막대**(`CategoryRatioBar`): 높이 30, 양 끝 둥글게, 칸 사이 2px. 칸 폭은 최소 8px을 먼저 주고 남는 폭을 개수 비율로 나눈다. 0장 카테고리는 칸이 없다. 칸 색은 1장 "카테고리 색" 표를 따른다. 화면 읽기는 막대 전체를 "쇼핑 6장, 문화생활 4장, …"으로 한 번에 읽는다. 처음 그려질 때 왼쪽부터 채워진다(`slow` 420ms, 애니메이션 줄이기면 바로).
6. **카테고리 알약**: 색 점(9px, 막대와 같은 색) · 아이콘 · 이름 · 개수 배지, `Wrap`으로 줄바꿈. 모두 `background` + 1.2px `darkGray` 차콜 테두리(개수 배지는 `chip` 채움)이고 채움 강조는 없다. 막대와 알약은 같은 데이터(기기 내 분류 포함)와 같은 순서를 쓴다: **개수 내림차순, 동점이면 카테고리 고정 순서(쇼핑→…→일정), 기타는 개수와 상관없이 맨 끝.**
7. 알약 줄 맨 끝(기타 바로 뒤)에 **"분석 제외" 알약**: 카테고리와 구분되게 `inkSub` 1.2px **점선** 테두리(선 4 · 빈칸 3), 색 점 없음, 자물쇠 아이콘 · "분석 제외"(`inkSub`) · 개수 배지. 0장이면 숨기고, 비율 막대에는 들어가지 않는다. 누르면 분석 제외 화면.
8. 하단 고정 탭바 3개(서랍·관심사·검색). 선택 탭은 `celadonSoft` 알약 배경 + 굵은 라벨. 관심사·검색은 빈 화면 자리만(안내 문구 한 줄).

### 8.2 카테고리 상세
1. 뒤로 버튼(아이콘만, 터치 영역 48).
2. 큰 제목(카테고리 이름 `title`) + **오른쪽 거대한 개수(`numHero`, `darkGray` 차콜)**.
3. 태그 칩 줄(가로 스크롤): 중립 칩은 `background` + `ink` 테두리 알약, **선택된 칩은 그 카테고리 색(`AppCategoryColors`) 채움 + 굵은 글자(w800) + `darkGray` 2px 테두리**(기타·정보처럼 밝은 색에서도 색만으로 구분하지 않게). 맨 앞 "전체" 칩. 같은 칩을 다시 누르면 해제.
4. 높이가 다른 **2열 엇갈림 그리드**: 카드 반경 28, 썸네일 색 블록, 왼쪽 아래에 날짜 배지(`MM.DD`, 흰색 알약). 칩 줄과 겹치지 않는다. 누르면 상세로 Hero 전환.

### 8.3 스크린샷 상세
들어온 목록(카테고리 전체 또는 선택된 태그로 거른 결과) 안에서 **좌우로 넘기는 `PageView`**다. 항목마다 한 페이지.
1. 배경 `celadon` 단색(휴지통 제스처를 끌 때만 다크그레이 쪽으로 어두워진다). 위쪽 바(페이지와 함께 움직이지 않음): 뒤로 버튼(흰 원) + 오른쪽 **위치 알약**(흰색, `numBadge`, 예: `3 / 42`, 휴지통 처리 후 전체 수가 줄어든다).
2. 가운데: **-2°**로 살짝 기울어진(드래그 중에는 기존처럼 더 기울어짐) 이미지 카드 + 오른쪽 위에 **카테고리 스티커**(아이콘 + 이름, 레몬 배경; 태그는 아래 정보 카드의 칩으로 그대로). 카드는 **흰 테두리 6px + 부드러운 그림자**(`cardShadow`, 블러 24)다. 카드는 **상단 바 아래(최소 16px 여백) ~ 정보 카드 위의 남는 공간을 최대한 채운다**: 폭은 영역의 최대 **78%**, 높이는 남는 공간 안에서, 비율은 **사진의 실제 폭/높이**(못 읽으면 0.62)를 지킨다. 테두리를 뺀 안쪽 비율이 사진과 같아 스크린샷이 잘리지 않고 전체가 보인다. 세로로 긴 사진(예: 0.45)은 높이 기준으로 폭이 정해진다. 남는 공간이 240보다 작으면 페이지가 스크롤된다.
3. 하단 카드(`background`, 위쪽 반경 32): 첫 줄 "출처 · 10.19 14:14"(보조 글자) + **카테고리 버튼**(레몬(`lemon`) 배경을 채운 알약, 테두리 없음, 아이콘 + 이름 + 연필, 누르면 수정 시트, 자기 폭만 차지하고 카드 오른쪽 안쪽 여백에 붙는다); 요약 제목(`cardTitle`); 연셀라돈 해시태그 칩들; **레몬 버튼** "같은 관심사 캡처 N장 더 보기" + 화살표. 페이지를 넘기면 이 카드가 그 항목 내용으로 바뀐다.
4. 양옆 페이지는 미리 만들어 둔다(`allowImplicitScrolling`). 첫·마지막 장에서는 더 넘어가지 않고 멈춘다(`ClampingScrollPhysics`).
5. **Hero**는 현재 페이지의 이미지 카드에만 걸린다. 뒤로 가면(또는 아래로 닫으면) 그리드의 **지금 보던 항목 썸네일**로 돌아가고, 그리드는 그 타일이 화면에 보이게 미리 스크롤해 둔다(항목이 카테고리 수정·휴지통으로 그리드에서 빠졌으면 목록 순서상 가장 가까운 남은 항목).
6. 상세에서 카테고리를 바꾸면 **현재 화면에서는 그 항목이 그대로 유지**되고(칩만 바뀜), 그리드로 돌아가면 반영된다.

#### 제스처 (이미지 카드에서)
| 동작 | 결과 |
|---|---|
| ← → 좌우로 넘기기 | 목록 안에서 이전/다음 항목(경계에서 멈춤) |
| ↓ 아래로 쓸어내리기 | 닫기(그리드 복귀). 카드가 손가락을 따라 내려가며 살짝 줄어듦. 화면 높이의 18% 이상 끌거나 아래 속도 800px/s 이상이면 닫고, 아니면 스프링 복귀 |
| ↑ 위로 던지기 | **휴지통으로**(아래 모션 명세). 삭제 수단은 이것뿐이다(보이는 메뉴·버튼 없음). 화면 읽기용 동작은 접근성 항목 참고 |
| 탭 | **전체 화면 보기**(검은 배경). 두 손가락으로 확대·축소(1~5배, `InteractiveViewer`), 확대 중에는 한 손가락으로 이동. 닫기: 왼쪽 위 X(48) 또는 확대하지 않은 상태에서 아래로 쓸기(120px 이상 또는 800px/s 이상, 놓으면 닫힘·모자라면 복귀). 확대 중에는 쓸어도 닫히지 않는다. 사진은 기기 원본, 지워졌으면 "사진이 없어요" |
| 정보 카드 영역의 세로 드래그 | 페이지 스크롤(화면이 낮거나 글자가 클 때). 닫기·휴지통 제스처는 **이미지 카드에만** 걸려 충돌하지 않는다 |

#### 첫 진입 안내 (한 번)
- 기기 모드에서 상세에 처음 들어오면 화면 전체에 `darkGray` 60% 덮개 + 가운데 흰 원(56) 위 화살표 + "위로 밀면 휴지통으로 가요"(`sectionTitle`, 흰색) + 레몬 [알겠어요](`AppButton`). 240ms(`base`) 페이드 인, 애니메이션 줄이기면 바로.
- 덮개는 터치를 막지 않아 바로 카드를 끌어 볼 수 있다. **[알겠어요]를 누르거나 끌기 시작하면** 닫히고, 설정(기기 저장)에 기록해 다시 뜨지 않는다. 화면 읽기는 덮개를 안내 한 덩어리로 읽는다.

#### 휴지통 모션 명세 (값은 모두 `AppGesture` 토큰)
- **진행도** `t = clamp(위로 끈 거리 / (화면 높이 × 1/3), 0, 1.15)`. `t = 1`이 기준선.
- **끄는 동안**: 카드가 손가락을 따라 올라감 · 배율 1 → 0.86 · 왼쪽으로 최대 0.06rad(약 3.4°) 기울어짐 / 배경이 셀라돈에서 다크그레이 쪽으로 어두워짐(불투명도 = `t × 0.72`) / 화면 상단 중앙에 휴지통 아이콘(흰 원 56)이 나타나 `t`에 따라 0.6배 → 1.4배로 커지고 투명도도 `t`에 비례.
- **기준선 통과**(`t ≥ 1`): 아이콘 배경(원)이 `#111111`, 아이콘이 레몬(`#EDE7B3`)으로 바뀌고(`trashActiveBackground`·`trashActiveIcon`) 1.18배로 튐 + **햅틱(`mediumImpact`) 1회**. 기준선 아래로 내려갔다가 다시 넘으면 한 번 더. (기준선 전이라도 **놓을 때 위쪽 속도 ≥ 1200px/s**이고 24px 이상 끌었다면 통과로 본다 — 스치기만 한 것은 무시)
- **놓았을 때**
  - 통과: 카드가 휴지통 아이콘 위치로 **빨려 들어간다** — 420ms(`slow`), `emphasized` 곡선, 배율 → 0.1, 투명도 1 → 0, 이동은 아이콘 중심까지. 끝나면 저장소에 휴지통 반영 → 목록에서 제거 → **다음 항목(같은 자리)**이 나타남(0.92배·투명 0.4 → 1, 240ms). 마지막 장이었으면 **이전 장**, 목록이 비면 그리드로.
  - 미통과: `AppMotion.spring`으로 제자리 복귀(위치·배율·기울기, 배경·아이콘도 원래대로).
- **되돌리기**: 하단에 다크그레이 알약 스낵바 "휴지통으로 옮겼어요 · [되돌리기]"(4초, 되돌리기 글자는 레몬). 누르면 저장소 복원 + 상세가 열려 있으면 원래 위치에 다시 끼워 그 페이지로 이동. 상세가 닫혔어도(목록이 비어 그리드로 나간 경우) 스낵바는 유지되고 그리드가 갱신된다.
- **애니메이션 줄이기**: 끄는 동안 카드·배경·아이콘 효과와 햅틱이 없다. 기준선을 넘겨 놓거나 화면 읽기 동작 "휴지통으로 옮기기"를 실행하면 **효과 없이 즉시 처리**(전환·스낵바 모두 애니메이션 없음).
- **접근성**: 화면에 보이는 대체 버튼은 없다. 대신 이미지 카드(라벨 "캡처 이미지")에 **Semantics 커스텀 동작 "휴지통으로 옮기기"**가 있어 스크린 리더(TalkBack)의 동작 메뉴에서 위로 던지기와 같은 동작을 실행한다. 위치 알약은 "42장 중 3번째"로 읽힌다.
- 휴지통은 **앱 안의 개념**이다. 실제 기기 사진은 지워지지 않는다(→ spec F-06).

### 8.4 카테고리 수정 시트
- 위쪽 반경 30의 `background` 시트, 뒤는 상세 화면이 어둡지 않게 비친다. 오른쪽 위 닫기(×) 버튼(`chip` 원).
- 제목 "이거 어디 서랍이야?", 부제 "AI는 **X**라고 했어요"(`autoCategory`, X는 굵게, 보조 글자).
- **2열 타일**(흰색, 1px `border`, 반경 18): 아이콘(`chip` 원 배경)·이름. 선택(현재 값)은 **`lemon` 채움 + 2px `ink` 테두리 + 체크**. 일곱 번째(기타)는 왼쪽 열.
- 아래 `darkGray` 버튼(흰 글자): 선택값이 **현재 카테고리와 같으면 "응, X 맞아"**, **다르면 "이 서랍으로 옮기기"**. 누르면 저장(`categorySource = USER`) 후 시트가 닫히고 상세·홈 집계에 반영된다. 같은 값도 저장된다(사용자 확인).

### 8.5 첫 분석
- 배경 `darkGray`. 상단 `re:mine`(흰색, 콜론만 celadonDeep) + 오른쪽 알약(진행 중 `DIGGING…`, 끝나면 `DONE`).
- 거대한 진행 숫자(`numHero` 128, `celadon`) + 진행 중 "/ N장 꺼냈어요", **끝나면 "N장 꺼냈어요"**(새 캡처가 없으면 "새로 꺼낼 캡처가 없어요"). 남은 예상 시간(서버가 알려 준 호출 간격으로 처음부터 어림, 몇 장 처리하면 실제 속도)과, 서버 응답을 기다리는 동안 움직이는 가는 막대 + "N장을 분류하는 중이에요"(모션 줄이기면 글자만).
- 진행 중에만 그 아래 "정리하는 동안 화면을 켜 두세요"(`caption`, 흰색 70%). 이 화면이 떠 있고 끝나지 않은 동안 앱이 화면 꺼짐을 막는다(안드로이드 `FLAG_KEEP_SCREEN_ON`, 권한 없음). 끝나거나 홈으로 나가면 푼다.
- 가운데 카드 4장은 **방금 분류된 실제 캡처 썸네일 + 그 카테고리 라벨**(레몬 알약)이다. 오래된 것이 왼쪽, 최신이 오른쪽이고 모자라면 빈 반투명 카드가 남는다. 민감·금융으로 숨긴 캡처는 올리지 않는다.
- 칩 위에 짧은 제목 "지금까지 찾은 것", 그 아래 카테고리별 개수 칩(흰색 알약, 이름 + 개수 `chip` 배지) `Wrap`.
- 아래 버튼: 진행 중 "홈에서 먼저 볼래요", **끝나면 "홈으로"**. 끝나도 자동으로 넘어가지 않는다.
- 맨 아래 보안 문구는 박스 없이 작은 회색 글씨(12) 한 줄 + 작은 자물쇠(12): "은행·메신저·민감한 캡처는 기기 밖으로 전송되지 않아요". 좁거나 글자가 크면 줄바꿈된다.
- `START_SCREEN=analysis`(개발용)는 가짜 진행값(128 / 300)과 장식 카드 띠(색 블록 + "→ 쇼핑" 스티커)를 쓴다.

### 8.6 사진 권한 (기기 모드)
- **첫 실행 순서**: 사진 권한 → 이미지 분석 동의 → 알림 안내 → 첫 분석. 동의·알림 안내는 같은 `IntroChoiceScreen`(아이콘 · 제목 · 설명 · 점 목록 · 버튼 둘)이다.
- **허용**: 바로 앱. **일부만 허용**: 맨 위에 레몬 안내 띠("고른 사진만 보여. 새 스크린샷은 자동으로 가져올 수 없어." + [다시 고르기] 테두리 버튼), 아래는 평소 화면.
- **거부**: 레몬 원 아이콘 + 제목 "사진을 볼 수 있어야 해"(`display`) + 설명(`body`, 반말) + 버튼 둘 [권한 허용] [설정 열기]. 권한을 이미 한 번 요청했는데도 거부면 설명이 "설정에서 직접 허용해줘"로 바뀌고 [설정 열기]가 레몬(주 버튼)이 된다. 설정에서 돌아오면 다시 확인한다.
- 버튼은 `AppButton`(알약, 최소 높이 52, 레몬 채움 또는 테두리). 화면이 낮으면 스크롤.
- **디버그 OCR 측정 화면**(디버그 빌드, 홈 워드마크 길게 누르기): 앨범 칩 · 썸네일 격자(선택 시 레몬 덮개 + 체크) · 아래 패널(진행·결과 한 줄, 버튼들). 패널은 화면 높이의 40%까지만 쓰고 넘치면 스크롤한다. 화면에는 OCR 원문을 띄우지 않는다.

## 9. 접근성

- 터치 영역 최소 48×48. 아이콘만 있는 버튼은 `Semantics` 라벨 필수.
- 장식(썸네일 콜라주, 스티커)은 `ExcludeSemantics`. 큰 개수·진행 숫자는 읽히게 한다("쇼핑 42장").
- 선택 상태는 색에만 의존하지 않는다(체크·굵은 테두리).
- 애니메이션 줄이기를 따른다([모션](#5-모션)).

## 10. 반응형 규칙 (넘침 방지)

화면 크기·글자 크기·폰트 로딩 여부에 따라 글자 폭이 달라지므로 **글자가 들어가는 곳에 고정 폭·높이를 쓰지 않는다.**

- 가로: `Expanded`/`Flexible` + `maxLines`·말줄임(`ellipsis`), 줄어들 수 있는 알약은 `FittedBox(scaleDown)`. 여러 개가 나란히 놓이면 `Wrap`.
- 세로: 내용 높이에 맞추는 `minHeight`(예: 관심사 카드 196, 탭바 72, 시트 타일 64). 화면이 낮거나 글자가 크면 페이지가 스크롤된다(상세·첫 분석은 "최소 높이 = 화면 높이 + `spaceBetween`"으로 높이가 넉넉하면 아래 카드가 바닥에 붙음).
- 장식(콜라주·이미지 카드)은 사용 가능한 폭·높이에 비례하고, 너무 좁으면 숨기거나 단순화한다.
- **지원 범위**: 최소 320×480, 글자 1.3배까지 overflow 0. 더 작은 창(240×320)과 폰트를 못 불러온 경우(기본 폰트는 글자 폭이 훨씬 넓음)도 넘침 없이 그려지게 테스트한다(`app/test/layout_*_test.dart`).
